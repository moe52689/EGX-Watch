# EGX Watch 1.4.0 · build 5

An Android 8+ Kotlin/Compose Material 3 application with Room, Coroutines/Flow and
WorkManager. This release extends the existing app. New watchlists are empty;
upgrades preserve selections and last saved quotes/NAVs.

## Install the versioned APK

Use `artifacts/EGX-Watch-v1.4.0-build5-2026-09-25-debug.apk` (or the identical
`artifacts/EGX-Watch-debug.apk`). Copy it to the phone and open it from your file
manager. Allow installation from that source if Android asks. Install over the
previous locally signed version to preserve its database. This is a debuggable,
development-signed APK, not a Play release.

```sh
adb install -r artifacts/EGX-Watch-v1.4.0-build5-2026-09-25-debug.apk
adb shell am start -n app.egxwatch/.MainActivity
```

A different signing certificate cannot upgrade the installed app. Do not uninstall
just to bypass a signing mismatch: that deletes local history. APKs are ignored by
Git; build artifacts can also be generated by the repository's Actions workflow.

## Start collecting

1. Read the first-run explanation. **No pre-installation history is required,
   purchased, synthesized or downloaded by the analytics pipeline.**
2. **Markets:** search and validate stocks, ETFs and supported funds. The saved
   catalogue contains 296 stocks, 167 funds and one ETF; it is not a guaranteed
   complete/current register. An authorized gateway can search additional identities.
3. **Settings:** connect an authorized HTTPS current-price gateway and configure
   the EGX schedule, holidays, exceptions and fallback providers. No EGX feed is
   configured by default. Vendor API credentials belong on the server, not in the app.
4. **Gold:** refresh XAU/USD using the documented keyless current-price Gold-API
   adapter, then optionally enable its independent schedule. Units are USD per troy
   ounce. It is not Egyptian retail gold, an EGX gold fund NAV or an exchange trade.
5. **Home → instrument:** explore your collected chart, observations, maturity,
   available/building indicators, source, timestamps and explainable analysis.
6. **Alerts:** filter Stocks / Gold / System, mark read, dismiss and open details.
   Configure stock rules in instrument/settings screens and gold rules on Gold.
7. **Settings → Storage:** see collection statistics, export a password-encrypted
   market archive, or confirm deletion of one instrument's/all collected history.

## Data providers and free-feed limits

For EGX, supply a legitimate HTTPS gateway implementing
[the current-price provider contract](docs/PROVIDER_CONTRACT.md): search, validation,
quote and market status. **A historical endpoint is not required.** No secret vendor
key goes into the APK. Production never falls back to mock prices.

Gold's default optional source is [`api.gold-api.com/price/XAU/USD`](https://gold-api.com/docs),
which documents keyless current prices. Its [terms](https://gold-api.com/terms) permit
application integration but prohibit abuse and provide no uptime/accuracy guarantee.
The adapter caches for at least 30 seconds; normal monitoring defaults to 15 minutes.
No paid/history endpoints are used. Optional primary/fallback gold gateways use the
same quote contract with `GLOBAL:XAUUSD`, type `COMMODITY`, currency `USD`, kind `SPOT`
and a provider-snapshot timestamp. Only the documented public source is bundled;
additional independent gold sources require configuration.

Undocumented EGX website scrapers remain disabled. In particular, TradingView's
terms prohibit the automated/non-display use required here. See
[source policy](docs/FREE_FEEDS.md). An old saved quote is never relabelled as fresh
because a request failed or the phone reconnected.

## Forward history, analytics and charts

- Indexed, deduplicated observations preserve provider time separately from receipt
  time, identity, decimal price, currency, provenance and optional supplied fields.
  Older data is rejected. Revised same-date NAV replaces that date's sample rather
  than increasing maturity. Provider/series changes do not merge incompatible prices.
- Maturity progresses through INITIALIZING, INTRADAY, SHORT_TERM, DEVELOPING and
  ESTABLISHED using samples, observed sessions, occupied polling slots and gaps.
  Each indicator has an independent sample/session/missing-data requirement.
- Early intraday momentum becomes available first. Locally sampled session SMA/EMA,
  RSI, MACD, Bollinger upper band, volatility, ATR, support/resistance and drawdown
  unlock independently. Sampled OHLC does **not** claim official exchange OHLC.
  Volume is used only when supplied; absent valuation/news/context remains absent.
- Scores expose their components. Coverage confidence is not a probability of profit.
  Stale, insufficient or discontinuous data does not generate opportunity alerts.
  Local deterministic explanations require no LLM or private-account data.
- Vico Compose charts (Apache 2.0) support TODAY/5D/1M/3M/6M/1Y/ALL, with unavailable
  long ranges disabled; touch price/time inspection, zoom/pan, sampled candles,
  latest-level overlays, supplied cumulative volume and clickable event markers.
  Bucketed price lines use an actual last sample, never a fabricated mean quote.
- Raw observations are compacted after 90 days only after usable session summaries
  exist; old unusable records are trimmed while keeping the latest per series.
  Long charts use bounded session queries and at most about 500 rendered points.
  Aggregate retention is currently up to the first 4,000 sessions in chart queries.

Stock opportunity alerts retain configurable thresholds, confidence, quiet hours,
cooldown, daily cap and material-transition suppression. Gold supports price above /
below, percent movement over a period, abnormal movement, and new locally observed
highs/lows. First observations establish baselines; rule state and cooldowns persist.
New-high/low means within the observed lookback, not an all-time market record.
Optional legacy every-check price alerts remain an explicit separate setting.

## Background and security

Independent EGX/gold WorkManager jobs use 15/30/60/120/custom intervals >=15 minutes.
Android execution is approximate and affected by Doze, force-stop, network and battery
restrictions. Visible-screen polling shares persisted interval guards with workers.
EGX normal polling respects its configured Cairo calendar; an explicit off-hours
collection option does not enable off-session opportunity alerts. Gold has its own
editable time zone, days, windows and closed dates; provider availability does not
prove a trading session is open. No authoritative remote calendar is configured.
No foreground-service workaround or exact-alarm claim is made.

TLS validation stays enabled; redirects and oversized/slow responses are bounded.
Provider cooldowns, exponential backoff, jitter and Retry-After persist. Android
private storage and disabled OS backup protect the local database; it is not SQLCipher
encrypted at rest. Exports use password-derived AES-256-GCM with random salt/nonce,
PBKDF2-HMAC-SHA256 (210,000 iterations), authenticated headers and streamed rows.
Passwords/keys/tokens are never logged or stored. Export is a consistent logical
market-database archive; in-app import is not implemented. See
[archive format](docs/FORWARD_RELEASE.md) and [security notes](docs/SECURITY_OPERATIONS.md).

Set `ANDROID_HOME` or ignored `local.properties` with `sdk.dir`.

Output: `app/build/outputs/apk/debug/app-debug.apk`. Tests use mocks, never a live
market API. See [actual verification](docs/VERIFICATION.md).

Manual acceptance: upgrade without uninstalling; confirm retained selections and
saved timestamps, empty fresh-install watchlist, first-run guidance, source failures,
repeated snapshots, offline caching, separate gold/EGX schedules, unavailable chart
ranges, alert taps/cooldowns, export, confirmed reset, dark/light and RTL layouts.
An authorized EGX current-price connection is needed to test real EGX collection.

## Architecture and remaining work

Existing WatchRepository, gateway/failover, price notifications and manual DI remain.
ObservationRepository owns local collection/aggregation. AnalyticsRepository invokes
AdaptiveQuantitativeEngine or GoldAnalyticsEngine. Separate GoldMarketRepository,
GoldSessionManager, worker and GoldAlertManager manage gold. Room v5 migrations add
observations, sessions, series metadata, gold config/status/rules/state, preferences
and alert center. Earlier imported historical caches/assessments are cleared during
upgrade; saved watchlist quotes and notification history remain.

Limitations: no bundled authorized live EGX source; directory coverage is incomplete;
no remote calendar synchronization, external LLM, fundamentals/news, official daily
candles, backtested profit probabilities, in-app archive restore or guaranteed mobile
execution. Gold rules have per-rule cooldowns but do not yet share stock opportunity
quiet hours/daily caps. UI supports system RTL layout with English copy; a complete
Arabic translation remains pending. See [release details and file map](docs/FORWARD_RELEASE.md).

Recommended next milestone: deploy an authorized **current-price** EGX backend with
calendar updates, independent monitoring and push delivery. Validate the accumulating
local analytics against observed outcomes and add encrypted archive restore. Historical
subscriptions must remain optional.
